# LabGuard · 实验室人员异常行为识别系统

公开网页：https://shaoranhu.github.io/lab-safety-demo/

这是系统的公开前端。配置的在线后端提供独立账号注册登录、两路视频上传或预设 RTSP 输入、YOLO 姿态基线与实验规则识别、异常截图和按时间筛选的 CSV 下载。框与关键点由后端绘制，前端不伪造识别结果。

前端托管于 GitHub Pages；当前后端通过临时 HTTPS 通道连接运行电脑。电脑关机、休眠、断网或服务停止时，网页仍可浏览，但注册和识别暂不可用。页面会显示实际连接状态，不把离线状态伪装成正常运行。

使用时点击“注册 / 登录”，上传测试视频或选择管理员预设的测试流。未提供真实实验室数据集时，模拟流仅用于验证连接。这里的规则不是经过验证的正式异常行为模型，不应作为安全决策依据。

此仓库仅包含公开前端文件和外部访问检查工作流，不包含账号数据库、视频、模型权重或私有配置。
